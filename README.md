# CAPI

A Dockerized FastAPI backend for NVIDIA AI integrations.

## Prerequisites

- Docker

## Getting Started

1. Clone the repository:
   git clone https://github.com/azaalijani06-glitch/CAPI.git
   cd CAPI

2. Add your environment variables (like your NVIDIA API key) to the docker-compose.yml environment.

3. Run the application:
    ./start.sh
